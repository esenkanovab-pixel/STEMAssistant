# STEM Assistant

Рабочий MVP на Next.js App Router, TypeScript и Tailwind CSS. Интерфейс, STEM-словарь и генерация викторин доступны на кыргызском, русском и английском.

## Запуск

Нужен Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Для production: `npm run build`, затем `npm start`.

## Возможности

- Поиск словаря по названиям и определениям на любом из трёх языков; фильтры STEM.
- Создание и редактирование уроков: класс, направление, цель, материалы, этапы с длительностью, связанные термины, печать и режим проведения урока.
- Конкретные планы для инерции и дробей, общий редактируемый шаблон для остальных тем.
- Термины урока фильтруются по предмету. Пользователь может добавить свой термин и определение.
- Генерация викторин по встроенным темам или определениям пользователя, редактирование вопросов и ключей ответа, сохранение нескольких игр.
- Игровое прохождение: один вопрос за раз, выбор ответа, правда/ложь, короткий ответ, очки, серии верных ответов, пояснения и разбор.
- Викторины связываются с уроком; при переходе из урока подставляются его термины.
- Журнал попыток, средний процент и выгрузка CSV.
- Данные и язык сохраняются в localStorage. Начальные уроки и результаты пустые, чтобы не смешивать демонстрационные оценки с реальными попытками.
- Адаптивный интерфейс, подписи полей, клавиатурное управление, уведомления об ошибках хранилища.

## Ограничения демо

Обычные локальные попытки доступны в одном браузере на одном устройстве. Результаты игр по ссылке хранятся на сервере и доступны учителю по отдельному ключу сессии. Аккаунтов и проверки личности учеников пока нет. Очистка данных браузера удалит записи. Уроки и собственные термины сохраняют введённый текст без автоматического перевода. Кыргызские учебные формулировки стоит проверить с преподавателем перед широким использованием.

Локальная генерация работает по материалу: для инерции есть банк ситуационных вопросов; для остальных терминов — вопросы по определениям. Это не AI-генерация произвольной темы. Неизвестная тема требует материала в формате `Термин: определение` (одна запись на строку) или серверного AI-ключа. Если разных вопросов выбранного типа меньше запрошенного количества, создаётся доступное число без повторов. Класс сохраняется как метка; сложность локального банка по классам автоматически не адаптируется. Короткие ответы проверяются по точному совпадению без учёта регистра, внешних пробелов и завершающей пунктуации. Очки за верный ответ: 100, бонус за серию до 100. Итоговая учебная оценка считается отдельно по числу верных ответов.

Генерация никогда сама не запускает игру: учитель сначала просматривает и при необходимости правит вопросы. Сохранённые записи предыдущего MVP продолжают читаться.

## AI для произвольных тем

В `.env.local` задайте серверный `OPENAI_API_KEY`, при необходимости `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`). Перезапустите или пересоберите приложение, включите «Использовать AI» в генераторе. Ключ не передаётся в браузер. Тема и материал отправляются в Responses API с JSON Schema, `store: false`; результат дополнительно валидируется на сервере.

Эндпоинт работает только на localhost с проверкой origin и ограничением 5 запросов в минуту. Он не предназначен для публичного платного сервиса без авторизации; перед размещением нужны вход, квоты по пользователю и постоянный лимитер. Реальный запрос к модели не проверен: ключ не предоставлен. Обработка ответов проверена с имитацией API. Документация: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses).

## Подключение Supabase

Подготовлен адаптер `lib/storage.ts`: `loadCloud` и `saveCloud` для уроков, результатов, викторин и терминов, а также `supabase/schema.sql` с RLS. Интерфейс работает локально до реализации входа, даже при наличии переменных окружения. Если старая схема уже установлена, выполните только блоки создания quizzes/terms и их политик.

1. Создайте проект Supabase и выполните SQL-схему один раз.
2. Скопируйте `.env.example` в `.env.local`, укажите URL и публичный anon key. Не используйте service role key в браузере.
3. Добавьте вход пользователя через Supabase Auth и переключите загрузку/сохранение на `loadCloud`/`saveCloud` после успешного входа. Используйте тот же клиент или экспортируйте его из адаптера.
4. Обработайте ошибки и синхронизацию явно; локальные данные автоматически в облако не переносятся.

Текущая схема хранит записи владельца. Для отдельных аккаунтов учителей/учеников потребуются таблицы классов, членства и соответствующие RLS-политики. Авторизация и работа с реальным Supabase ещё не тестировались, поскольку ключей нет.

## Подробный STEM-словарь
Карточки открываются нажатием на термин. Все 11 встроенных терминов имеют простое и стандартное объяснение, пример на кыргызском, русском и английском; подходящие термины содержат формулы с обозначениями и условиями применения. Схемы созданы в SVG. Для инерции, дробей, площади, энергии, силы, переменной и цепи доступны интерактивные примеры.

В подробной карточке можно добавить собственные пояснения на выбранном языке и прикрепить JPG/PNG/WebP до 5 МБ. Изображение уменьшается до 1000 пикселей и сохраняется локально в JPEG. Фото, подписи и изменения встроенных карточек пока хранятся только в браузере (`termDetails`); для переноса этих дополнений в Supabase потребуется расширить адаптер синхронизации и добавить хранилище изображений. Переполнение локального хранилища отображается как ошибка, предыдущие данные сохраняются.

У ассистента нет личного API-ключа для передачи приложению. Подписка ChatGPT не настраивает OPENAI_API_KEY автоматически. Альтернативный Sign in with ChatGPT требует регистрации подходящего клиента и отдельной авторизации; эта интеграция пока не реализована. https://developers.openai.com/siwc/quickstart

## Игры по ссылке и коду

1. Создайте, проверьте и сохраните викторину. В её карточке нажмите «Играть по ссылке», затем «Создать сессию».
2. Передайте ученикам ссылку или шестизначный код. Страница входа: `/play`. Ученик вводит код, имя или псевдоним и отвечает на вопросы.
3. Ответы проверяются на сервере после завершения. До отправки результата API не выдаёт правильные ответы и объяснения. После завершения доступен разбор.
4. В карточке учителя результаты обновляются каждые 5 секунд. Кнопка «Добавить в журнал» переносит попытки в локальный журнал без дублей для дальнейшего CSV-экспорта.
5. «Завершить приём ответов» запрещает новые отправки; уже сохранённый результат остаётся доступен учителю. Ученик, который ещё не отправил ответы, после закрытия сессии отправить их не сможет.

Сессия содержит неизменную копию вопросов на момент создания. Для обновлённых вопросов создайте новую сессию. Ключ учителя хранится в браузере отдельно от ученической ссылки; его можно скопировать из раскрывающегося блока и восстановить доступ по коду и ключу. Не передавайте этот ключ ученикам. Это отдельный доступ к демонстрационным результатам, а не полноценный аккаунт учителя.

Сессии, ответы и результаты сохраняются в `.local-games/sessions.json` на сервере. Папка исключена из Git и архива исходников. Нужен записываемый диск и один процесс приложения: очередь записи и атомарная замена файла не предназначены для нескольких серверов или serverless. Для размещения замените адаптер `lib/session-store.ts` транзакциями постоянной базы, добавьте авторизацию, квоты и политику хранения данных. Демо ограничено 100 сессиями, 200 попытками на сессию и 60 изменяющими запросами в минуту на адрес. При исчерпании лимита отображается сообщение. Имя участника не проверяется, отдельные попытки с новым идентификатором разрешены. Не используйте демо как защищённый экзамен.

Для других устройств нужен доступный сервер в общей сети. localhost и 127.0.0.1 обозначают устройство, на котором открыта ссылка. Откройте приложение по локальному сетевому адресу компьютера учителя и создайте ссылку там. Доступ с отдельного физического устройства ещё не проверен; он зависит от сети и правил доступа к порту. Брандмауэр автоматически не изменяется.

9 октября 2026 демонстрация запущена на **http://localhost:3001** из-за другого проекта на порту 3000. Команда запуска: `npm start -- --port 3001`. Локальные записи браузера привязаны к адресу и порту; записи со старого адреса автоматически не переносятся. Серверные сессии остаются в одной папке проекта при смене порта.

## Локальные кабинеты

`/` - пространство учителя с уроками, викторинами, сессиями и журналом. `/student` - кабинет ученика: сохранённое имя, вход по коду, история завершённых игр, средний результат, очки и повторный разбор ответов. Между пространствами можно переключаться через ссылки в шапке.

После успешной серверной отправки попытка и полный разбор сохраняются в браузере (`stem-student-v1`). Повторная отправка той же попытки не создаёт дубль. Новое имя применяется к будущим играм; имя в уже завершённых попытках сохраняется. Если браузер не смог сохранить данные, результат остаётся у учителя на сервере, а ученику показывается сообщение. Результаты игр, пройденных до появления кабинета, автоматически в него не переносятся.

Это один локальный профиль браузера, а не авторизация или изоляция пользователей. На общем устройстве его история доступна всем пользователям браузера. Синхронизация между устройствами и настоящие аккаунты потребуют Supabase Auth и политик доступа.

## Классы и задания
В разделе «Классы и задания» учитель создаёт класс и получает код для учеников. Можно назначить сохранённый урок или викторину и срок. Назначение сохраняет копию материала; изменения оригинала не меняют уже выданное задание. Для обновления результатов нажмите «Обновить».
Ученик сохраняет имя в /student и вступает по коду класса. Урок открывается с этапами и отмечается учеником как изученный. Викторина открывается по своему игровому коду; учитель видит последний результат для имени и количество ошибочных попыток по вопросам.
Классы сохраняются в .local-games/classes.json, викторины в .local-games/sessions.json. Ключи учителя хранятся в браузере (stem-class-access-v1); сохранённый ключ позволяет восстановить доступ. Список классов и изученных уроков ученика хранится в stem-student-v1. Это демо без проверки личности: одинаковые имена объединяются в отчёте; после изменения имени нужно вступить заново. Сроки информационные, выполнение после срока доступно. Для публикации нужны аккаунты, база данных, ограничение запросов и разграничение доступа. Ключи и локальные результаты исключены из архива.

## Сводка класса
В кабинете учителя каждый класс содержит сводку: выполненные задания, невыполненные задания после срока и средний процент по последним попыткам викторин. Каждая строка соответствует одному заданию одного ученика. Доступны фильтры Все / Выполнено / Не выполнено / Просрочено. Кнопка Скачать CSV выгружает отфильтрованные строки с именами, заданиями, статусами, баллами, сроками и датами результатов. CSV использует UTF-8 с BOM и защиту от формул электронных таблиц. Сведения других учеников, не вступивших в класс под этим именем, в сводку не входят.

# Самостоятельный запуск STEM Assistant

1. Откройте файл `STEM-Assistant.code-workspace` в VS Code.
2. Откройте меню **Терминал → Создать терминал**.
3. Выполните команду:

```powershell
npm.cmd run dev -- --port 3001
```

4. После сообщения **Ready** откройте http://localhost:3001.

Сервер работает, пока открыт его терминал. Для остановки нажмите **Ctrl+C**. При следующем показе выполните ту же команду. Если порт уже занят запущенным STEM Assistant, используйте открытый сервер; для второго экземпляра остановите первый.

Можно также выбрать **Терминал → Запустить задачу → STEM Assistant: запустить MVP** или дважды нажать `start-mvp.cmd` в папке проекта.

При первом запуске на другом компьютере установите Node.js и выполните `npm.cmd ci` перед командой запуска. Запуск демо не требует ключей Supabase или OpenAI. Генерация произвольных тем через внешний ИИ требует отдельного серверного ключа; встроенные вопросы доступны без него.

Пространство учителя: http://localhost:3001. Кабинет ученика: http://localhost:3001/student. Для демонстрации создайте викторину по инерции, проверьте вопросы, создайте игру и откройте ученическую ссылку в другом окне браузера.

Личные учебные материалы хранятся в браузере, а классы и игровые сессии — в папке `.local-games` проекта. Для сохранения демо используйте тот же адрес и браузер. Не удаляйте эти данные перед показом.
